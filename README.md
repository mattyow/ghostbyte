# Ghost Byte

A proportional pixel typeface — pixel construction without the monospace grid.
382 characters, 601 glyphs, small caps, oldstyle and tabular figures, fractions,
and four stylistic sets.

Free under the [SIL Open Font License 1.1](OFL.txt).

## Repo layout

```
sources/             Editable master. Save from Glyphs as .glyphspackage.
fonts/               Generated binaries: otf, ttf, woff2, woff. Do not hand-edit.
index.template.html  Source for the specimen site. Edit this.
index.html           Generated by build.py. Do not hand-edit.
build.py             Regenerates fonts/, the zip, and index.html from the OTF.
OFL.txt              License. Must ship with every copy of the font.
```

Anything under `fonts/`, plus `index.html` and the release zip, is build output.
It's committed anyway because Netlify serves the site directly from this repo,
so the download links need real files at those paths.

## Building

```sh
pip install fonttools brotli
python3 build.py sources/GhostByte-Regular.otf
```

`build.py` regenerates every web format from the OTF, rebuilds the download zip,
and writes `index.html` from the template — embedding the woff2 and reading the
character count, glyph count, metrics, and file sizes out of the font itself.
Those numbers are never typed by hand, so they can't drift out of date.

Export the OTF from Glyphs first, then run the build. The script warns if the
font's name table is missing its copyright (nameID 0) or license (13/14).

## Releasing

1. Bump the version in the Glyphs file and in `VERSION` in `build.py`.
2. Export the OTF, run the build, commit.
3. Tag: `git tag v1.001 && git push --tags`
4. Cut a GitHub Release from the tag and attach the zip, so the download URL
   stays stable for anyone linking to it.

Pushing to `main` auto-deploys the site to Netlify.
